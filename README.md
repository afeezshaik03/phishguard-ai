### 🔑 Key Highlights
- 🧠 **ML Model** — Random Forest trained on **549,346 URLs** with **96.4% accuracy**
- 🌐 **Browser Extension** — Chrome/Brave extension scanning every URL automatically
- 🚨 **4-Level Alerts** — Color-coded notification bar (Safe/Low/Suspicious/Dangerous)
- 📊 **SOC Dashboard** — Live Streamlit dashboard with charts, IOC tracker & alert logs
- 🔍 **Threat Intel** — VirusTotal API integration (70+ antivirus engines)
- ⚡ **Real-time** — Sub-second prediction speed via Flask REST API
